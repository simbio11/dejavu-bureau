# 🕰️ 데자뷔 관리국 (가제)

한 사람의 인생을 나무로 키우는 미스터리 게임.
선택마다 시간선이 갈라지고, 플레이어는 어느 가지든 이어가거나 과거로 돌아가 새 가지를 칠 수 있다.
진행은 가지가 아니라 **관리자의 기억**에 쌓이고, 다른 인생에서 알아낸 것을 **데자뷔로 심어** 고정점을 깬다.

## 지금까지 확정 (2026-10-10)

- 목표 구조: 미스터리 + 의뢰 혼합
- 주인공: 챕터마다 정해진 인물, 플레이어는 시간선 관리자
- 톤: 현실 인생극 + SF 액자(시간선 관리국)
- 분기: 무제한 분기·되감기, 진행은 기억(수첩)에 쌓임
- 1장 반전: 크게 — 1장 끝에 "서진도 데자뷔를 받고 있었다" 공개("관리자 = 다른 가지"는 시즌 후반 후보로 보류)
- 기존 "가지치기(게임 진화 엔진)"와는 별개 프로젝트
